# demo_lata

Source demo cho giao diện quản trị và API LATA.

## Nội dung

- `webapp/src`: giao diện quản trị demo.
- `backend-api/src`: mã nguồn API Express dùng cho thiết bị, cảm biến, bơm, báo cáo và quản trị dữ liệu đo.

Repo này chỉ chứa phần `src` để trình bày/demo, không chứa `.env`, token, mật khẩu hoặc dữ liệu chạy thật.
